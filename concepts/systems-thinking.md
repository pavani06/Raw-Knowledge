# Systems Thinking

The applied discipline of understanding how system structure — feedback loops, time delays, accumulations — produces behavior over time. Moves beyond slogans about "everything being connected" toward operationally useful tools for designing solutions that work.

Systems thinking is the qualitative, applied branch of [[system-dynamics]]. Where system dynamics adds computer simulation to test models, systems thinking provides the mental models, causal mapping techniques, and facilitation methods that make the methodology accessible to busy practitioners who do not have a PhD from MIT.

## Key Insights

- Core problem addressed: [[policy-resistance]] — well-intentioned solutions that work in the near term but cause the problem to return, often worse ([[sources/2026-06-25-systems-thinking-for-leaders-designing-solutions-that-work]])
- Primary diagnostic tool: [[causal-loop-diagrams]], which map how goals, decisions, side effects, and the actions of other actors create [[balancing-feedback]] and [[reinforcing-feedback]] loops
- The [[iceberg-model]] frames the challenge: managers see only what is above the waterline (intended effects), while the unintended consequences operate below the waterline through long time delays
- Replaces the [[open-loop-mental-model]] (identify → gather → evaluate → select → implement) with a feedback worldview
- Learning tools include [[management-flight-simulators]] for experiential learning and the [[group-modeling-process]] for collaborative system mapping

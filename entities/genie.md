# Genie

[[entities/databricks|Databricks]]' natural language to SQL tool that enables non-technical
users to query data using plain English. Mentioned in the [[concepts/agent-tracing|agent tracing]]
context: first-line support teams can use Genie's text-to-SQL capability to query centralized
trace data for operational health monitoring without writing SQL.

# Open-Loop Mental Model

The default mental model most people use to approach problems: identify the issue → gather data → evaluate alternatives → select optimal choice → implement. Problem solved. A linear, one-pass view of decision-making that ignores feedback.

> [!inference] The open-loop mental model is the root cause of [[policy-resistance]]. Because it assumes implementation is the final step rather than the start of a feedback cycle, decision-makers are blindsided when their solutions trigger unintended consequences that feed back and undermine their goals.

## Key Insights

- Pervasive in organizations: project plans, strategic planning, process improvement initiatives all implicitly assume this linear flow ([[sources/2026-06-25-systems-thinking-for-leaders-designing-solutions-that-work]])
- Contrasts with the feedback worldview of [[systems-thinking]], where every decision changes the world, creating new information that conditions the next decision in a never-ending cycle
- Reinforced by everyday experience: in the short run, actions often appear to work, providing powerful (but misleading) confirmation of the linear model

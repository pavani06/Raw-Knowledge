# Agent Bricks

[[entities/databricks|Databricks]]' platform for building production-grade AI agent
applications. Agent Bricks incorporates all five pillars of the Databricks production AI
framework (evaluation, observability, data foundation, orchestration, governance) as
out-of-the-box capabilities. Integrates with [[entities/mlflow|MLflow]] for automatic
LLM-as-judge evaluation and proactive monitoring.

Under active development as of June 2026: "we are building Agent Bricks to make all of
these operations out of the box for you, so that it's easy to implement production grade
AI applications in your enterprises."

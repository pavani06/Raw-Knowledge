# MLflow

Open source ML lifecycle platform and one of the foundational open-source technologies
that [[entities/databricks|Databricks]] is built on. In the agent evaluation context,
MLflow provides automatic [[concepts/llm-as-judge|LLM-as-judge]] capabilities — custom
LLM judges that run automatically on [[concepts/tracing-observability|traces]] for
continuous evaluation at scale. Mentioned as part of the [[entities/agent-bricks|Agent Bricks]]
platform for out-of-the-box LLM judges and proactive monitoring.
